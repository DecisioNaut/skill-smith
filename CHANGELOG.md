# Changelog

All notable changes to agent-builder-skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-02-13

### Added

**Core Skill:**
- Initial SKILL.md with comprehensive step-by-step instructions
- 8-step process for building Agent Skills from online resources
- Interactive resource gathering guidance
- Three complexity levels (simple/medium/full)
- Validation checklist and troubleshooting

**Reference Documentation:**
- VALIDATION.md with complete validation rules
- BEST_PRACTICES.md with agent-friendly writing guidance
- SPECIFICATION.md summarizing the Agent Skills spec

**Scripts & Tools:**
- validate_skill.py for validating skills against specification
- generate_skill.py for scaffolding new skills from templates
- Support for all three complexity levels in generator

**Templates & Assets:**
- 7 resource gathering templates (GitHub, docs, APIs, etc.)
- Comprehensive checklists for completeness
- Interactive request templates
- Example-driven templates

**Example Skills:**
- Simple example: code-review (SKILL.md only)
- Medium example: api-integration (with references/)
- Complete reference files for examples

**Project Infrastructure:**
- README.md with quick start and usage examples
- LICENSE (Apache 2.0)
- CONTRIBUTING.md with contribution guidelines
- .gitignore for common files
- GitHub-ready structure

### Documentation

- Complete FAQ section in README
- Usage examples for common scenarios
- Links to official Agent Skills resources
- Validation and testing guidance
