# Contributing to agent-builder-skill

Thank you for your interest in contributing to agent-builder-skill!

## How to Contribute

### Reporting Issues

If you find bugs or have suggestions for improvements:

1. Check if the issue already exists in the [Issues](../../issues) section
2. If not, create a new issue with:
   - Clear description of the problem or suggestion
   - Steps to reproduce (for bugs)
   - Expected vs actual behavior
   - Any relevant examples

### Submitting Changes

1. Fork the repository
2. Create a new branch for your changes: `git checkout -b feature/your-feature-name`
3. Make your changes following the guidelines below
4. Test your changes thoroughly
5. Commit with clear, descriptive messages
6. Push to your fork and submit a pull request

### Guidelines

#### For SKILL.md Updates

- Keep instructions clear, actionable, and agent-friendly
- Use concrete examples where possible
- Maintain the existing structure and tone
- Test changes by building a skill using the updated instructions

#### For Scripts

- Include error handling and helpful error messages
- Add comments explaining complex logic
- Follow Python best practices (PEP 8)
- Test scripts with various inputs

#### For References

- Keep content focused and well-organized
- Use clear headings and structure
- Link to authoritative external sources
- Update the main SKILL.md if references change significantly

#### For Examples

- Ensure examples follow the Agent Skills specification
- Validate examples with `skills-ref validate` if possible
- Include comments explaining key decisions
- Keep examples realistic and practical

### Code of Conduct

- Be respectful and constructive
- Welcome newcomers and help them learn
- Focus on what's best for the community
- Provide helpful feedback

### Questions?

Feel free to open an issue for discussion or clarification before starting major changes!
